# Security Policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or store reviews.

Include affected version/browser, reproduction steps, impact, and any minimal proof needed to confirm the issue. Remove page content, credentials, tokens, personal domains, and unrelated private data before submitting.

## Scope

Relevant reports include unauthorized data access or transmission, permission misuse, settings isolation failures, message validation bypasses, source-package privacy leaks, and extension-context injection.

General support questions and non-sensitive bugs belong in the bug report template.

## Response and release

Maintainers will validate privately, prepare a regression test where safe, re-run package/privacy validation, and coordinate disclosure. This file promises no fixed response or remediation deadline.
